# PRD — 샤오홍슈 제품 홍보영상 자동 생성 SaaS

> 문서 버전: v0.2 (Draft)
> 작성일: 2026-07-05 (v0.1) → 2026-07-06 리서치 반영(v0.2)
> 작성/오너: 1인 개발자 (PM 겸 개발)
> 상태: 초안 — "리서치 필요"였던 타겟지역·가격·경쟁사는 **부록 C(deep-research 결과)**로 채움.

## 0. TL;DR

셀러/브랜드가 **제품 사진과 간단한 정보만 입력하면**, 샤오홍슈(小红书/RED) 톤에 맞는
**세로형(9:16) 15~60초 시연·홍보 영상**을 자동으로 만들어주는 SaaS.

MVP는 "진짜 AI 영상 생성(text-to-video)"이 아니라 **이미지 기반 슬라이드 + 모션 + 샤오홍슈
스타일 템플릿(자막/이모지/BGM) + AI 카피라이팅** 조합으로 6주 내 출시 가능한 범위로 정의한다.
고비용·저품질 리스크가 큰 순수 T2V는 v2 이후로 미룬다.

핵심 성공 가설: **"편집 인력·예산이 없는 중소 셀러는, 완벽한 영상보다 '5분 안에 게시 가능한
그럴듯한 네이티브 영상'을 원한다."**

## 1. 문제 정의 (Problem Statement)

### 1.1 배경
- 샤오홍슈에서 제품을 노출·전환시키려면 **감성적이고 네이티브한(광고 티가 안 나는) 짧은
  시연/홍보 영상**이 사실상 필수다. 정적 이미지 게시물의 도달·전환이 영상 대비 낮다.
- 그러나 이런 영상은 "잘 만든 광고"가 아니라 "실사용자가 찍은 듯한 톤"이 핵심이라, 템플릿화가
  어렵고 손이 많이 간다.

### 1.2 페인 포인트
| 대상 | 현재 겪는 문제 |
|---|---|
| 중소 브랜드 / D2C 셀러 | 촬영·편집 인력이 없음. CapCut(剪映)로 직접 편집하려니 시간·러닝커브·톤 감각 부족 |
| 왕홍 마케팅 대행사 | 다품목·대량 제작 시 편집자 리소스가 병목. 단가 압박 |
| 공통 | 샤오홍슈 특유의 톤앤매너(자막 스타일, 이모지, BGM 트렌드)를 매번 맞추기 어려움 |

### 1.3 현재 대안과 그 한계
- **직접 촬영 + CapCut/剪映 편집**: 무료지만 시간·감각·일관성 부족. 대량 생산 불가.
- **왕홍/편집 대행 외주**: 품질은 좋지만 건당 단가가 높고 리드타임이 김. 소량·테스트에 부적합.
- **범용 AI 영상툴(Runway/Pika 등)**: 샤오홍슈 네이티브 톤·자막 문법에 특화되어 있지 않음.

### 1.4 우리가 노리는 빈틈 (Wedge)
> "범용 AI 영상툴"도 "고가 외주"도 아닌, **샤오홍슈 포맷·톤에 특화된 반자동 영상 공장.**
> 품질은 외주보다 낮아도, **속도·단가·일관성**으로 이긴다.

## 2. 목표 & 비목표

### 2.1 목표 (Goals)
- G1. 가입 후 **첫 영상 생성까지 5분 이내** 경험 제공.
- G2. 샤오홍슈에 그대로 올려도 어색하지 않은 **네이티브 톤 영상** 산출.
- G3. 1인 개발·6주 내 출시 가능한 기술 범위로 MVP 확정.
- G4. 초기 유료 전환 가설 검증 (건당 과금 vs 구독).

### 2.2 비목표 (Non-Goals, 이번 버전 제외)
- N1. 샤오홍슈로의 **실제 자동 업로드/게시** (API·계정 리스크 큼 → 수동 다운로드/게시).
- N2. **라이브 커머스** 연동.
- N3. 완전 자유도의 영상 편집기(타임라인 에디터). MVP는 "템플릿 채우기" 수준.
- N4. 순수 text-to-video 생성 모델 자체 학습/파인튜닝.

## 3. 타겟 사용자 & 페르소나

> ⚠️ **타겟 지역 확정이 선결 과제.** 중국 내수 브랜드냐 / 해외(한국·동남아) 진출 브랜드냐에
> 따라 페르소나·결제수단·현지화·마케팅 채널이 전부 갈린다. (§9 R1 참조)

### 3.1 잠정 1차 페르소나 (가설)

**페르소나 A — "해외 D2C 셀러 지연 (Jiyeon)"** *(초기 타겟 유력 후보)*
- 한국/동남아 기반, 샤오홍슈로 중국 소비자에게 뷰티·패션·리빙 소품을 판매.
- 중국어 네이티브가 아니라 **톤·자막 문법을 스스로 맞추기 어려움**.
- 예산 제약으로 왕홍 외주는 부담. "일단 여러 개 찍어서 테스트"하고 싶음.
- 결제: 해외 카드(Stripe) 가능 → **기술적으로 접근이 쉬움**.

**페르소나 B — "왕홍 대행사 PM 리웨이 (Li Wei)"**
- 다수 클라이언트 제품을 대량으로 소화해야 함. **처리량(throughput)**이 핵심 가치.
- 건당 단가·API 연동·화이트라벨에 관심.

**페르소나 C — "중국 내수 소상공인"** *(잠재 최대 시장이나 진입장벽 큼)*
- 결제(WeChat/Alipay), 데이터 규제, 마케팅 채널이 완전히 다름 → **MVP에서는 후순위 권장**.

### 3.2 초기 타겟 권고 (리서치로 뒷받침됨 — 부록 C-R1)
MVP는 **페르소나 A(해외/크로스보더 D2C 셀러, 특히 한국·동남아)** 중심으로 **확정 권고**.
리서치 근거(신뢰도 高):
- **RED이 크로스보더로 확장 중**: 2025.6 홍콩에 본토 외 첫 사무소 개설, 원래 해외직구 가이드로 출발 → 해외 브랜드 콘텐츠와 구조적 궁합.
- **동남아 기반이 큼**: 말레이시아가 본토 외 2위 시장. 지역 소셜커머스 수요도 확대.
- **RED은 구매 전 '종초(种草)' 리서치 엔진**: 400M+ MAU, 하루 ~800M 검색(2026.5). 뷰티/패션/식품/웰니스/라이프스타일, 여성 88%·18~35세 스큐 = 해외 브랜드 타겟 바이어와 정확히 일치.
- **내수(C)는 데이터 현지화(PIPL/DSL/CSL + CAC 반출심사) 장벽** → 1인 MVP엔 부담. 단, **제품 이미지/정보만 다루고 중국 최종소비자 PII를 취급하지 않는 B2B 구조면 회피 가능** → 해외 셀러 B2B 프레이밍이 규제상으로도 유리.
- **대행사(B)는 유력한 2차/B2B2C 채널**: 풀서비스 대행 리테이너가 월 ¥3만~10만(~$4.2k~14k, 신뢰도 中)이라 대량 자동화툴에 지불 여력 있음.

> ⚠️ **해외 셀러 온보딩 시 반드시 고지할 제약**(부록 C-R1): 판매하려면 기업 스토어(전문계정+사업자등록) 필요, 개인 스토어는 뷰티/식품 판매 불가·검색 가중치 ~50%↓·라이브 판매 불가. **해외 법인은 중국 법인 없이 巨光(Juguang) 광고 집행 불가** → 우리 제품은 "광고 집행"이 아니라 "콘텐츠(노트) 제작"에 포지셔닝해야 함.

## 4. 유저 스토리 (User Stories)

에픽 단위로 정리. `[MVP]` 표기가 이번 버전 범위.

### Epic 1 — 온보딩 & 입력
- `[MVP]` US-1.1 셀러로서, 회원가입 후 **제품 이미지 여러 장을 업로드**하고 싶다. 촬영 원본을 재활용하려고.
- `[MVP]` US-1.2 셀러로서, **제품명·핵심 셀링포인트·타겟 감성**을 짧은 폼으로 입력하고 싶다. 영상 카피의 근거가 되도록.
- `[MVP]` US-1.3 셀러로서, **카테고리(뷰티/패션/리빙/식품 등)와 영상 스타일(언박싱/사용법/리뷰)**을 고르고 싶다. 톤이 맞는 템플릿을 받으려고.

### Epic 2 — AI 카피/스크립트 생성
- `[MVP]` US-2.1 셀러로서, 입력만 하면 **샤오홍슈 톤의 후킹 카피·자막 문구·해시태그 후보**가 자동 생성되길 원한다.
- `[MVP]` US-2.2 셀러로서, 생성된 **문구를 수정/재생성**할 수 있길 원한다. 마음에 안 들 때 손보려고.
- `[Should]` US-2.3 셀러로서, 문구를 **중국어/한국어/영어**로 볼 수 있길 원한다.

### Epic 3 — 영상 생성
- `[MVP]` US-3.1 셀러로서, 업로드 이미지 + 생성 카피가 **9:16 세로 영상(15~60초)으로 자동 조립**되길 원한다.
- `[MVP]` US-3.2 셀러로서, **샤오홍슈 스타일 자막/이모지/전환효과/BGM 템플릿**이 자동 적용되길 원한다.
- `[MVP]` US-3.3 셀러로서, **BGM/템플릿을 몇 개 프리셋 중에서 교체**할 수 있길 원한다.
- `[MVP]` US-3.4 셀러로서, 렌더링 진행 상태를 보고 **완성되면 미리보기·다운로드(MP4)**하고 싶다.
- `[Could]` US-3.5 셀러로서, **AI 아바타/보이스오버**로 실제 시연자처럼 연출되길 원한다.

### Epic 4 — 계정·크레딧·결제
- `[MVP]` US-4.1 셀러로서, **남은 생성 크레딧**을 보고 싶다.
- `[MVP]` US-4.2 셀러로서, **크레딧을 구매/구독**할 수 있길 원한다.
- `[Should]` US-4.3 셀러로서, **생성 이력(라이브러리)**에서 과거 영상을 다시 받고 싶다.

### Epic 5 — 게시 지원 (비-업로드)
- `[Should]` US-5.1 셀러로서, **추천 해시태그·게시 최적 시간**을 안내받고 싶다. (자동 게시는 아님)

## 5. 기능 명세 (Functional Spec)

### 5.1 입력 모듈
- 이미지 업로드: 최대 N장(예: 3~10장), JPG/PNG/WebP, 장당 용량 제한. 자동 리사이즈/크롭(9:16 세이프영역).
- 제품 정보 폼: 제품명, 카테고리, 셀링포인트(불릿 3~5), 톤/무드(예: 청량/고급/귀여움), 언어.
- 스타일 선택: 영상 유형(언박싱/사용법/비교리뷰/무드컷), 길이(15/30/60초), 템플릿 프리셋.

### 5.2 AI 카피/스크립트 엔진
- LLM(Claude API)으로 **씬별 스크립트 구성**: 후킹(0~3초) → 문제/니즈 → 제품 → 셀링포인트 → CTA.
- 산출물: 씬별 자막 텍스트, 화면 문구, 해시태그 후보, (Should) 다국어 번역.
- **가드레일**: 과장·의료/효능 단정 표현 필터, 샤오홍슈 심의 민감어 회피(§7 참조).

### 5.3 영상 조립/렌더링 엔진 (핵심 기술 리스크)
- **MVP 방식(권장): 이미지 기반 슬라이드 + 모션(켄번즈/줌/팬) + 자막/이모지 오버레이 + BGM**을
  **프로그래매틱 템플릿**으로 렌더링.
- 씬 구성: 이미지 ↔ 자막 씬을 타임라인에 자동 배치, 비트 싱크(간단한 BGM 마디 기반) 전환.
- 출력: 1080×1920 MP4, 15~60초. 워터마크(무료 플랜) 옵션.
- 렌더링은 **비동기 큐 → 워커**에서 처리, 완료 시 알림.

### 5.4 라이브러리/이력
- 생성물 저장(오브젝트 스토리지), 썸네일, 재다운로드, 재생성(입력 프리필).

### 5.5 크레딧/결제 (리서치로 가격 확정 — 부록 C-R2)
- **모델: 크레딧 기반 구독**(순수 건당 과금 X). 직접 경쟁자 Creatify가 검증한 구조를 벤치마크.
- **플랜(권고 시작값)**:
  - Free: 워터마크, 월 ~10크레딧(~2영상) — 획득 퍼널용.
  - Starter: **~$29~33/mo**, 100크레딧(~20영상), 워터마크 제거.
  - Pro: **~$49/mo**, 200~300크레딧 + 고급기능(아바타/배치/다국어).
- **가격 앵커**: 실효 단가 광고 문구는 "$2/영상"이나 진입 티어 실효가는 **~$3.9/영상**(5크레딧/영상)이 현실적. 크레딧은 ~2개월 만료 관행.
- **가격 상·하한**: 하한(플로어)=AI UGC툴 $2~4/영상, 상한(실링)=RED 풀서비스 대행 리테이너 월 $4.2k~14k. 우리는 "외주보다 압도적으로 싸고, 직접 편집보다 압도적으로 빠른" 중간을 점유.
- 결제: Stripe(해외 타겟). 크레딧 차감: 생성 1건 = N크레딧(길이/옵션 가변).
- ⚠️ **단위경제성 주의**: 이미지 기반 Remotion 렌더 원가는 영상당 수 센트대(추정)라 $2~4 가격에 마진 충분. 반면 **순수 T2V(Kling/Runway) API는 원가가 훨씬 높아** 가격/마진을 깨뜨릴 수 있음 → MVP에서 T2V 배제 결정을 재확인. (실측 원가는 부록 C 잔여 오픈 질문)

### 5.6 관리/운영 (내부)
- 템플릿·BGM 자산 관리(라이선스 관리 필수 §7), 사용량·실패율 모니터링, 프롬프트 버전 관리.

### 5.7 경쟁 지형 & 포지셔닝 (리서치 반영 — 부록 C-R3)
| 경쟁자 | 무엇 | 강점 | 우리에게 빈틈(=기회) |
|---|---|---|---|
| **Creatify** (最위협) | 이미지/URL → UGC 영상 자동화 | 이미지 1장 → 50+ 변형 자동 생성 | **TikTok/IG/YouTube 지향, RED 미특화**. 중국어 톤·RED 문법 없음 |
| Arcads | 스크립트 → AI 배우 UGC 광고 | AI 액터, 6000+ 고객 | 내장 에디터 없음(CapCut로 export 필요), RED 미특화 |
| CapCut/剪映 | 범용 편집 + AI 템플릿/자동자막 | 무료·거대 사용자층 | 범용툴. RED 제품영상 니즈를 "반자동 공장"으로 묶어주지 않음 |
| 순수 T2V(Kling/Runway/Pika) | 텍스트/이미지 → 생성영상 | 화려함 | 제품 형태 왜곡·중국어 자막 품질·원가 → 제품영상엔 리스크 |

> **방어 가능한 포지셔닝(신뢰도 高)**: **"샤오홍슈 특화 반자동 영상 공장"**.
> 범용툴들은 *제네릭 자동화 레이어*에서만 겹치고, **RED의 2025~2026 중장편(2min+) 영상 드라이브·중국어 자막 톤·极限词 심의 가드레일**은 아무도 안 채운 빈틈. 여기에 특화하는 것이 해자.
> - RED은 중장편 영상에 "올인": 500억 트래픽 지원·15개 콘텐츠 트랙, 2min+ 중영상이 2026.4 기준 체류시간 50%+ 돌파, 무료 4K 제공. → **우리 템플릿은 15~60초 숏폼뿐 아니라 중영상(≈1~3분) 포맷도 로드맵에 넣을 가치가 있음.**

## 7. 제약 · 리스크 · 현지화

### 7.1 콘텐츠 심의 / 현지화 (샤오홍슈 특수성 — 리서치 반영 부록 C-R4)
- **极限词/광고법 가드레일은 MVP 필수 기능**(신뢰도 高). 중국 광고법 제9조3항이 **国家级·最高级·最佳·最·第一·唯一** 및 동일/유사 의미어의 절대·최상급 표현을 금지. 위반 시 제57조로 **벌금 ¥20만~100만 + 심하면 영업허가 취소**.
- **가드레일 룰셋 설계(중요)**: 2023 SAMR《广告绝对化用语执法指南》이 **과벌상당(过罚相当) 원칙과 예외**를 도입 → *제품 성능/품질을 가리키지 않는* 절대어(서비스 태도·경영 이념·기업 문화·주관적 포부/목표, 오해 소지 없는 비제품 연결 표현)는 **비처벌**. 방림부(方林富) 사건(¥20만→¥10만 감경)이 계기.
  → LLM 필터는 **"제품 성능·품질에 대한 최상급 단정"만 차단**하고, 위 예외 카테고리는 허용하도록 정교하게. (무차별 차단 시 카피 품질 저하)
- 의료·효능 단정 표현도 별도 차단.
- "네이티브 톤"이 핵심 가치 → **템플릿·자막 문법·트렌드 BGM의 현지 감수** 필요. 초기엔 중국어 네이티브 감수자/레퍼런스 확보.
- 브랜드가 제공한 이미지의 **저작권·초상권(모델 포함)** 책임 고지(약관).

### 7.2 저작권/라이선스
- BGM·폰트·이모지·스티커 **상업적 사용 라이선스** 확보 필수. (무료 소스 오남용 시 리스크 큼)

### 7.3 기술/비용 리스크
- 렌더링 비용(특히 Lambda/T2V API)이 단위경제성 파괴 가능 → **크레딧 단가 설계에 렌더 원가 반영**.
- T2V 품질 편차 → MVP에서 배제한 이유.

### 7.4 일정
- 1인, MVP 6주. §8 로드맵 참조 (범위 초과 시 Should/Could 먼저 컷).

## 9. 성공 지표 (KPI) & 계측

### 9.1 North Star (가설)
- **주간 "다운로드까지 완료된 영상" 수** (실제 가치 실현 프록시).

### 9.2 핵심 지표
| KPI | 정의 | 초기 목표(가설) |
|---|---|---|
| TTFV (Time To First Video) | 가입→첫 영상 다운로드까지 시간 | 중앙값 ≤ 5분 |
| 재생성률 | 한 입력당 재생성 횟수 (↑이면 만족도↓ 신호일 수 있음) | 모니터링 (해석 주의) |
| 다운로드 전환율 | 생성 시작 → 다운로드 완료 비율 | ≥ 60% |
| 활성화율 | 가입자 중 ≥1개 영상 다운로드 비율 | ≥ 40% |
| 유료 전환율 | 무료→유료 | 벤치마크 후 확정 (§9 R2) |
| 렌더 성공률/시간 | 실패율, 평균 렌더 시간 | 실패율 <5% |

> ⚠️ **재생성률 해석 주의**: "재사용/재생성"은 만족도 프록시로 쓰되, *과도한 재생성 = 첫 결과가
> 나빴다*는 부정 신호일 수도 있음. "다운로드 전환율"과 **함께** 봐야 함.
